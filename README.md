OffKey for macOS
Просто отключите клавиатуру, чтобы протереть её, не выключая компьютер и не отправляя систему в сон.

О чём это?
OffKey - это минималистичное приложение без лишнего интерфейса, которое живёт в строке меню macOS (справа вверху, где часы и батарея).
Оно решает простую, но насущную проблему: как безопасно протереть клавиатуру MacBook или внешнюю клавиатуру, случайно ничего не нажав.
Не нужно выключать Mac, отключать Bluetooth или ждать засыпания. Просто нажали «Off Key» - клавиатура перестаёт отвечать на нажатия. Протёрли - «On Key» - работаете дальше.

Особенности
- Нет окна - только иконка в трее (строке меню).
- Один клик для отключения / включения клавиатуры.
- Безопасный выход - при закрытии приложения клавиатура автоматически включается (чтобы вы не остались без ввода).
- Идеально для чистки - никаких случайных нажатий, выключений или срабатываний горячих клавиш.
- Работает с встроенной и внешней клавиатурой Mac.

Быстрый старт:
1. Скачайте последнюю версию из раздела Releases.
2. Перетащите OffKey.app в папку Программы.
3. Запустите приложение (в первый раз macOS спросит разрешение - нажмите «Открыть»).
4. Разрешите доступ к управлению компьютером (см. ниже «Настройка доступа»).
5. После этого в трее появится иконка - всё готово к работе.

Часто задаваемые вопросы?
Можно ли случайно остаться без клавиатуры навсегда?
Нет. Вы всегда можете:
- Включить клавиатуру через меню (мышкой/трекпадом).
- Перезапустить Mac.
- Или просто выйти из OffKey - он сам включит клавиатуру.

Работает ли с внешней USB / Bluetooth клавиатурой?
Да, блокируются все события клавиатуры на уровне системы.

А мышка / трекпад отключается?
Нет. Только клавиатура. Мышка и трекпад продолжают работать - это сделано специально, чтобы вы могли управлять меню OffKey.

Почему нет окна?
Потому что окно здесь не нужно. Иконка в трее - самый быстрый и ненавязчивый способ.
